# יומי

אפליקציית כלים יומיים שמתאימה את עצמה לתפקיד שלך: **מפתח/ת, מעצב/ת, מורה או הורה**.
נכנסים עם שם (ואימייל לא חובה), בוחרים תפקיד, ומקבלים מסך בית, משימות וכלים שמתאימים לו.

| תפקיד | כלים |
|---|---|
| מפתח/ת | סטנדאפ יומי, טיימר פוקוס, מעצב JSON, סניפטים |
| מעצב/ת | מחולל פלטות, בודק ניגודיות WCAG, ממיר px↔rem, טיימר פוקוס |
| מורה | הגרלת תלמיד, חלוקה לקבוצות, מחשבון ציונים משוקלל, טיימר כיתה |
| הורה | רשימת קניות, מטלות וכוכבים לילדים, תפריט שבועי, טיימר זמן מסך |

ולכל התפקידים: מחשבון בסגנון iPhone עם היסטוריה, פתקים, מעקב הרגלים, ספירה לאחור לאירועים וחלוקת חשבון.

העיצוב בסגנון iOS: טאב-בר זכוכית צף, כותרות גדולות, רשימות מקובצות, החלקה למחיקה עם ביטול, ומצב כהה.

באפליקציית האנדרואיד הנתונים נשמרים במכשיר (localStorage), עם כמה חשבונות מקומיים. בתצוגה החיה ב-Claude הם נשמרים בענן ומסתנכרנים.

## מבנה

- `www/index.html` – כל האפליקציה (HTML/CSS/JS, בלי build)
- `capacitor.config.json` – הגדרות Capacitor שעוטף את האתר כאפליקציית אנדרואיד
- `.github/workflows/android.yml` – GitHub Actions שבונה APK בכל push ל-`main`

## לקבל APK לטלפון

1. מעלים את התיקייה ל-repo חדש ב-GitHub (ענף `main`).
2. בלשונית **Actions** רואים את הבנייה רצה (כ-5 דקות).
3. בסוף נוצר **Release** חדש עם הקובץ `yomi.apk`. פותחים את הדף מהטלפון, מורידים ומתקינים
   (צריך לאשר "התקנה ממקורות לא ידועים").

## להריץ מקומית

פשוט לפתוח את `www/index.html` בדפדפן.
