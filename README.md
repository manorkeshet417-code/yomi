# יומי

אפליקציית כלים יומיים שמתאימה את עצמה לתפקיד שלך: **מפתח/ת, מעצב/ת, מורה או הורה**.
נכנסים עם שם (ואימייל לא חובה), בוחרים תפקיד, ומקבלים מסך בית, משימות וכלים שמתאימים לו.

| תפקיד | כלים |
|---|---|
| מפתח/ת | סטנדאפ יומי, טיימר פוקוס, מעצב JSON, סניפטים |
| מעצב/ת | מחולל פלטות, בודק ניגודיות WCAG, ממיר px↔rem, טיימר פוקוס |
| מורה | הגרלת תלמיד, חלוקה לקבוצות, מחשבון ציונים משוקלל, טיימר כיתה |
| הורה | רשימת קניות, מטלות וכוכבים לילדים, תפריט שבועי, טיימר זמן מסך |

ולכל התפקידים: מחשבון בסגנון iPhone עם היסטוריה, פתקים, מעקב הרגלים, ספירה לאחור לאירועים וחלוקת חשבון.

העיצוב בסגנון iOS: טאב-בר זכוכית צף, כותרות גדולות, רשימות מקובצות, החלקה למחיקה עם ביטול, ומצב כהה.

## פותחים ומתקינים

האפליקציה היא אפליקציית ווב (PWA): **https://manorkeshet417-code.github.io/yomi/**

- **אנדרואיד (Chrome):** פותחים את הכתובת ולוחצים "התקנה" בכרטיס שבמסך הבית, או בתפריט ⋮ ← "התקנת אפליקציה".
- **iPhone (Safari):** כפתור השיתוף ← "הוספה למסך הבית".
- **מחשב (Chrome / Edge):** אייקון ההתקנה בשורת הכתובת.

אחרי ההתקנה האפליקציה נפתחת במסך מלא, עובדת גם בלי אינטרנט, ומתעדכנת לבד.

הנתונים נשמרים בדפדפן של המכשיר (localStorage), עם אפשרות לכמה חשבונות. בתצוגה החיה ב-Claude הם נשמרים בענן ומסתנכרנים.

## מבנה

- `www/index.html` – כל האפליקציה (HTML/CSS/JS, בלי build)
- `www/manifest.webmanifest` + `www/icons/` – שם, אייקונים וקיצורי דרך להתקנה
- `www/sw.js` – שומר עותק של האפליקציה כדי שתעבוד גם בלי אינטרנט
- `.github/workflows/pages.yml` – מפרסם את `www/` ל-GitHub Pages בכל push ל-`main`

## עדכונים

כל שינוי ב-`www/` עולה לאתר תוך כדקה. מי שפותח את האפליקציה מקבל את הגרסה החדשה, כולל מי שהתקין אותה למסך הבית.
